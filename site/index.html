03 怎么用上Install and invoke

从仓库安装 Skill

git clone https://github.com/ZZM112451/fluid-ui-skill.git
cd fluid-ui-skill
node scripts/manage.mjs install --agent codex

默认装到 ~/.agents/skills/fluid-ui，项目级安装加 --project <目录>。需要 Node.js 22+。

或者在 Codex 里直接说要什么

使用 $fluid-ui 优化当前表单。保留已有设计系统，
只改善错误、加载、取消和恢复反馈；
实施后运行相关测试。

显式调用 $fluid-ui 是可靠的；自动触发受宿主的描述预算与选择影响。
