# 有无 Fluid UI 的受控对照

日期 2026-11-04。比较五个相同类型任务：表单、导航、分步弹窗、数据密集页、搜索与展开卡。基线与增强由同一主会话模型的独立 Agent 上下文生成；增强读取本 Skill，基线不读。共同提示要求原生 Web、绿色强调、8px 间距、系统字体、保留业务、键盘、减少动态效果、小屏和状态反馈。

两组均尽力实现，没有人为削弱基线。模型参数继承主会话，未固定或另行切换模型。数据条目与产品文案不完全一致，因此不是严格像素对照或统计因果实验；无生产数据。

## 可复现证据
代码位于 [baseline](../../examples/comparison/baseline/form.html) 和 [enhanced](../../examples/comparison/enhanced/form.html)，各含五个同名页面。运行 `npm run dev`，另一个终端执行 `node scripts/compare.mjs`。如果本机浏览器不同，可设 FLUID_CHROMIUM。脚本用同一 Chromium 在 320/390/1280、reduced-motion 条件检查溢出、axe、控制台、标签与任务行为。

原始结果 [controlled-results.json](comparison/controlled-results.json)，十张截图在 [截图目录入口](comparison/screenshots/baseline-form.png)。独立增强测试另有 [39 项浏览器记录](comparison/enhanced-browser-results.json) 和 [axe 记录](comparison/enhanced-axe-results.json)，不能合并成相同任务的比较通过数。

## 同一量表
主观项 0=缺失/退化、1=部分满足、2=满足本任务。自动指标独立列出，性能没有同条件交互帧采样则不评分。评分者为本次工程 Agent，非盲测人类评审。

| 项目 | 基线 | 增强 | 依据与限制 |
|---|---|---|---|
| 视觉一致性 | 2 | 2 | 两组均保持绿色、系统字体与统一布局；看过十页截图拼图，未做像素级等同断言 |
| 状态正确性 | 2 | 2 | 各 7 项共同失败/取消/草稿/弹窗/筛选/搜索检查通过；非穷尽业务状态 |
| 可访问性 | 2 | 2 | 两组 axe 0 项违规、输入有标签；未做人类读屏验收 |
| 性能 | 未评分 | 未评分 | 两组运行依赖为 0，缺同条件交互帧测量，不推断更快 |
| 可维护性 | 2 | 2 | 两组均为小型自包含样例，无新增依赖；增强代码量更大 |
| 适度动画 | 2 | 2 | 无装饰循环动画，减少动态效果保留操作 |
| 需求符合度 | 2 | 2 | 覆盖五类任务和指定系统约束；仅限样例范围 |

共同扫描未见页面溢出或控制台异常。增强代码变长是成本，不是自动质量提升；本次没有观察到可量化的全面优势，不用于营销性提升百分比。

## 代表性既有项目试运行
[before](../../examples/comparison/trial/before.html) / [after](../../examples/comparison/trial/after.html) 为非生产项目“青叶工作台”表单副本。三处局部变化：错误 live 宣告、输入恢复清除旧反馈、取消文案。保留 Token、650ms 请求模拟、请求序号、重复提交保护与取消计时器，依赖变化 0。详见 [代码变化说明](../../examples/comparison/trial/changes.md)。

独立真实浏览器验证前后取消和失败均正确，after 新增输入清除旧反馈通过；axe 前后均 0 违规。未把样例称为真实上线项目，未修改用户现有学习任务应用。未验证暗色、RTL、字体放大与真机键盘在此试运行副本的效果，不能用主演示结果替代。
