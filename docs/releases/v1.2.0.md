## 发布说明 / Release notes

Fluid UI Skill v1.2.0 — Crystal Motion

Design interfaces that feel alive.

Fluid UI is an open-source UI design and interaction enhancement Skill for OpenAI Codex and other coding agents. It helps agents build polished, responsive, accessible interfaces while preserving existing design systems, application logic, and platform conventions.

Version 1.2.0 introduces Crystal Motion, an optional crystal-clear glass preset with luminous optical edges, subtle Aurora backgrounds, and continuous, interruptible spring motion.

### What's New

1. Crystal Motion — A New Visual Experience

Crystal Motion introduces a refined glass material and motion language:

- Nearly transparent glass surfaces with luminous edge highlights.
- Soft Aurora backgrounds and restrained blur.
- Velocity-preserving spring animations.
- Gesture-aware interactions and reversible transitions.
- Accessibility-conscious motion and visual fallbacks.

Crystal Motion is opt-in and does not replace the existing Liquid Glass v5 preset or the four foundational UI styles.

2. Twenty Interaction Patterns

Fluid UI includes design and implementation guidance for 20 interaction patterns, covering animation states, interruption, accessibility, performance, and platform adaptation.

Each pattern has an individual conceptual SVG illustration and documented acceptance criteria.

[Explore All 20 Interaction Illustrations](https://github.com/ZZM112451/fluid-ui-skill/blob/main/docs/SHOWCASE.md)

The illustrations communicate the intended interaction designs. They are not recordings of 20 independently implemented components.

3. Interactive Web Demonstrations

Explore the runnable reference implementations:

- [Crystal Motion Navigation Demo](https://github.com/ZZM112451/fluid-ui-skill/tree/main/demo/crystal-motion)
- [Liquid Glass Interaction Demo](https://github.com/ZZM112451/fluid-ui-skill/tree/main/demo/liquid-glass)

Open the [live Crystal Motion demo](https://zzm112451.github.io/fluid-ui-skill/demo/crystal-motion/) or [live Liquid Glass demo](https://zzm112451.github.io/fluid-ui-skill/demo/liquid-glass/). For local development, clone the repository and run `npm run dev`.

4. Design System Compatibility

Fluid UI preserves its four core design styles:

- Glass
- Material 3
- Minimal
- Tech

Three selection modes are supported: Auto, Preset, and Hybrid, with Subtle, Balanced, and Expressive motion intensity options.

5. Agent and Platform Guidance

- OpenAI Codex as the primary tested agent host.
- Implementation guidance for Web, Android Compose, Flutter, and React Native.
- State-driven interaction architecture.
- Keyboard, focus, reduced-motion, cancellation, and error-recovery considerations.
- Safe installation, conflict protection, version pinning, and rollback guidance.

Platform guidance does not imply that every platform implementation has been compiled or device-tested.

### Installation

Requires Node.js 22 or later.

```sh
git clone https://github.com/ZZM112451/fluid-ui-skill.git
cd fluid-ui-skill
node scripts/manage.mjs install --agent codex
```

### Example Usage

In Codex:

```text
Use $fluid-ui to improve this interface.
Preserve the existing design system and business logic.
Apply Crystal Motion only where appropriate.
Validate accessibility, interruption, and error states.
```

### Verification and Known Limitations

This release includes automated testing and packaging infrastructure for Linux and Windows.

Twenty interaction patterns have Crystal Motion design guidance, but only a subset is represented by runnable Web implementations. Native-platform equivalence and full cross-agent compatibility remain unverified.

Refer to the GitHub Actions results and verification reports for the actual test status.

### 中文介绍

让界面拥有生命力。

Fluid UI 是面向 OpenAI Codex 及其他编程 Agent 的开源 UI 设计与交互增强 Skill，帮助开发者在保留现有设计系统和业务逻辑的前提下，实现更加自然、流畅、可靠的界面体验。

### v1.2.0 主要更新

Crystal Motion 水晶玻璃预设

新增高通透水晶材质、精细发光边缘、柔和极光背景，以及支持速度继承和中断恢复的弹簧动画。

20 种交互模式

提供 20 种交互的设计与实现规范，每种模式均配有独立 SVG 概念效果图、验收标准和验证状态说明。

[查看全部 20 种交互展示](https://github.com/ZZM112451/fluid-ui-skill/blob/main/docs/SHOWCASE.zh-CN.md)

可运行 Web 演示

提供 Crystal Motion 导航实验台及 Liquid Glass 交互示例，支持本地启动和实际操作。

保留原有设计体系

继续支持 Glass、Material 3、Minimal、Tech 四种风格，以及 Auto、Preset、Hybrid 三种选择模式。

工程可靠性

提供状态管理、动画中断、失败恢复、无障碍、跨平台实施指导和安全安装机制。

当前限制

20 种交互均有设计规范与概念图，但尚未全部实现为独立可运行的 Crystal Motion 组件。跨平台原生实现仍需要进一步验证。
