# 代表性既有项目试运行

本试运行使用非生产的青叶工作台表单测试副本。仅读取表单基线，不将该实现用于五个独立增强页面。

保持原有绿色 Token、系统字体、8px 间距、请求模拟、650ms 时序、重复提交保护、请求序号、取消计时器和焦点恢复。依赖变化为 0。

三个局部改动：错误文本增加 aria-live；重新输入时清除已过期的请求结果，避免旧失败提示与已修改邮箱混淆；取消提示明确邮箱保留及可重试。原有异步取消实现已能屏蔽迟到响应，因此保留实现，没有用增加依赖或重构制造差异。

原始独立验证由 run-validation.mjs 执行；归档后的可复现回归见仓库 tests/browser/trial.spec.mjs，截图在 docs/verification/comparison/screenshots。
