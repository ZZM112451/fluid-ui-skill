# Liquid Glass v5

这是 Glass 下显式选择的预设，Skill 版本 1.1.0，设计版本 v5。依据用户交付包 index.html 的运行行为及 ACCEPTANCE.md；原始版本为批准设计的可运行重建，并非 AppBlock 字节级导出。不要宣称原生平台等价或将其当成完整生产应用。

## 视觉 Token
背景为浅蓝分层渐变，辅以低强度蓝/紫径向氛围；正文深石板蓝，次级文字冷灰蓝。accent `#307eae`，success `#168e76`；使用语义 onAccent/textMuted 等做实际合成对比检查。白字小按钮必要时采用同色相较深的可读派生色，不降低文字标准。玻璃为半透明白、白色边缘、背景模糊与柔和冷阴影；暗色用低透明白表面。模糊限局部，forced-colors/低性能回退为实色。

大卡片圆角 19–25px，浮动导航 25px，主按钮 13–15px。统一 easing `cubic-bezier(.22,1,.36,1)`；布局/形变 420–560ms，主题扩散约 720ms，反馈 300–420ms，成功停留约 2200ms。数值是参考起点，不是设备性能保证；强度可缩放幅度与节奏，但不可破坏已批准的连续关系。

## 八交互验收
| 模式 | 必须保留的连续行为 | 不可接受的替代 |
|---|---|---|
| 流体底部导航 | 持续存在的按钮；选中项图标+标签展开，其他缩小；一个背景块跟随实时布局位置与宽度；连点最终选中一致 | 切换时重建 DOM、每项独立背景淡入、终点跳跃 |
| 圆形主题扩散 | 独立完整新主题场景；圆心为实际主题按钮；扩散外保留旧主题；两方向和 reduced-motion 等效切换 | 单色圆罩、整个旧场景先换色、虚拟固定中心 |
| 计时胶囊 | 131px 左右紧凑态到可见暂停/播放/重置的连续宽度与圆角；时钟状态独立 | 展开时重置或暂停计时；替换成另一个面板 |
| 三步底部弹窗 | 三步横向滑动，同时改变实际容器高度；错误阻止推进；返回与成功 | 突然替换内容；先切内容再跳高度；固定高度截断 |
| 随滚动 FAB | 带标签宽胶囊 ↔ 圆形加号；方向和阈值控制，同一按钮 | 整体隐藏唯一入口、只淡出文字且容器不变 |
| 复制成功 | 仅通用双纸图标；await 真正写入后本地按钮变绿圆/勾，并有附近反馈；约 2.2s 恢复 | “COPY”文字图标、假成功、只有独立 toast |
| 表单校验 | 红边、短 shake、平滑展开错误；有效输入恢复；aria-invalid/描述同步 | 只变红或只抖动，读屏不可知；非法推进 |
| 锚定下拉 | 从触发附近变换进入，当前项标记，选择及关闭 | 与锚点无关的全屏菜单；隐藏选项仍可 Tab 聚焦 |

## 工程约束
统一状态与取消策略详见 [连续状态形变](../morphing.md)。导航与侧向页面使用 inert/aria-hidden 隔离不可交互页但保留绘制；动画退出后再隐藏，不以 hidden 抢先切断退出帧。计时用截止时间重算而非仅 setInterval--，销毁清理；收起控件不可聚焦。分步高度按自然内容测量并限制到可用视口，长内容内部滚动，支持字体放大和键盘。

主题快照要复制当前滚动位置、禁用副本交互/读屏、去掉重复 ID，完成与取消都清理 WAAPI fill。复制使用请求序号屏蔽过期写回，失败文字不能带成功类，恢复计时只作用于最新操作。保存防双击，焦点在分步/关闭后有合理归属。

下拉三项只演示选择状态，不宣传三套完整材质引擎。次级页面只是交互上下文。剪贴板受 localhost/HTTPS 和权限约束。

## 平台与验证
按当前 [平台入口](../platforms.md) 选一个指南。Web 工程示例使用原生 button/dialog、CSS 布局过渡和独立场景 clip-path；Compose 可用稳定 key/Transition/AnimatedContent（保持同一组件身份）与绘制裁剪；Flutter 用稳定 Key、AnimationController/约束布局/ClipPath；RN 使用现有原生/动画能力并核实布局属性支持，不能假设 useNativeDriver 支持 width。四个平台均先建状态机、处理系统返回、字体、安全区和取消；这些适配建议不代表原生编译通过。

测试必须检查中间帧和终态、连点、错误/恢复、真实复制或受控成功/拒绝、主题两方向、reduce-motion、小屏和焦点。比较原型与工程化示例，说明因可用性做的修正，不重新设计。详见 [验证基线](../verification.md)。
