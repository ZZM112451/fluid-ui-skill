# 平台入口

只加载实际平台指南；不为覆盖平台引入组件库。

- [Web](platforms/web.md)：React、Vue 与浏览器原生能力。
- [Android Compose](platforms/android.md)：Kotlin、Material 3、生命周期与系统返回。
- [Flutter](platforms/flutter.md)：Dart、系统组件、约束与状态。
- [React Native](platforms/react-native.md)：TypeScript、原生语义、导航与线程。

指南为实现建议，实际编译/设备证据单独记录；Web 成功不能作为移动端通过证据。
