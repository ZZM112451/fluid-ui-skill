# Expandable Search Field

## 适用与禁用
空间紧且搜索为次任务；主要任务为搜索时保持常显。

## 触发与状态
收起 → 聚焦/展开 → 输入 → 结果/空/错 → 关闭。通用 focus/pressed/disabled 由原生控件承担；不适用的业务状态不伪造。

## 动画参数
160–220ms 宽度容器变化，输入框不缩到不可用。强度通过 Motion Token 调整，减少动态效果取消空间运动。

## 中断和恢复
取消旧查询，保留或清除策略明确；Esc 先关结果再关闭。

## 无障碍
搜索 label，结果数量 polite，键盘结果导航；不要只靠放大镜。

## 性能约束
输入防抖 150–300ms 起点，测实际延迟；虚拟化大量结果。

## 平台适配
移动端处理键盘/返回；Web search input；现有平台搜索组件。核对项目实际依赖版本，不假定跨框架 API 相同。

## 验收
快速输入旧结果不覆盖新；清空、关闭重开、无结果与错误测试。记录运行环境、命令、结果和未验证项。
