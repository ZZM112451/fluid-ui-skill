# Skeleton Content Transition

## 适用与禁用
首次加载且已知内容形状；不替换短暂后台刷新现有内容。

## 触发与状态
pending → content/empty/error；已加载后后台刷新保留内容。通用 focus/pressed/disabled 由原生控件承担；不适用的业务状态不伪造。

## 动画参数
淡入 120–180ms，骨架可静态；不设强制最短等待。强度通过 Motion Token 调整，减少动态效果取消空间运动。

## 中断和恢复
请求切换中断旧内容，超时提供重试；取消移除 busy。

## 无障碍
容器 aria-busy，骨架隐藏读屏，文字说明加载中。

## 性能约束
尺寸与真实内容接近减少 CLS；不用大面积持续 shimmer。

## 平台适配
各平台 placeholder 组件或静态块，无依赖回退。核对项目实际依赖版本，不假定跨框架 API 相同。

## 验收
失败绝不无限骨架；慢网、空列表、尺寸变化与减少动态效果。记录运行环境、命令、结果和未验证项。
