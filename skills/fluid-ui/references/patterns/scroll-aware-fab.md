# Scroll-aware FAB

## 适用与禁用
列表中单个高频新增操作；不用于多主操作。

## 触发与状态
展开 ↔ 收缩；禁用明确；滚动停止不反复跳变。通用 focus/pressed/disabled 由原生控件承担；不适用的业务状态不伪造。

## 动画参数
向下超阈值收缩，向上展开，160–200ms；阈值起点 12px。强度通过 Motion Token 调整，减少动态效果取消空间运动。

## 中断和恢复
用户聚焦或菜单打开时不收起；滚动与点击冲突让点击完成。

## 无障碍
缩起仍有可访问名字与完整点击面积；不藏唯一任务入口。

## 性能约束
passive 滚动监听+rAF，每帧最多一次；固定布局预留空间。

## 平台适配
移动端使用原生 FAB，桌面可固定工具栏替代。核对项目实际依赖版本，不假定跨框架 API 相同。

## 验收
滚动抖动不闪烁；键盘焦点可见；遮挡和安全区测试。记录运行环境、命令、结果和未验证项。
