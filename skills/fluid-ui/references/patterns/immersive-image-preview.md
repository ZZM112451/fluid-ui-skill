# Immersive Image Preview

## 适用与禁用
用户主动查看媒体细节；无图或无版权不伪造素材。

## 触发与状态
关闭 → 加载 → 可查看/错误 → 关闭；缩放有上限。通用 focus/pressed/disabled 由原生控件承担；不适用的业务状态不伪造。

## 动画参数
进入 180–240ms，reduced-motion 淡入或直接出现。强度通过 Motion Token 调整，减少动态效果取消空间运动。

## 中断和恢复
关闭取消加载，手势冲突明确；旋转窗口保留合理缩放。

## 无障碍
原生 modal、关闭/Escape、alt、键盘缩放、焦点恢复。

## 性能约束
按需大图，限制解码尺寸，离开释放对象 URL/纹理。

## 平台适配
保留系统返回与安全区，Web dialog；原生媒体组件。核对项目实际依赖版本，不假定跨框架 API 相同。

## 验收
加载失败、长图、大图、键盘退出、缩放和横竖屏。记录运行环境、命令、结果和未验证项。
