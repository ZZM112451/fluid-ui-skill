# Empty and Error States

## 适用与禁用
列表无数据、过滤无匹配或请求失败；三者必须区分。

## 触发与状态
loading → content/empty/error；retry → loading；筛选空可清除。通用 focus/pressed/disabled 由原生控件承担；不适用的业务状态不伪造。

## 动画参数
通常无需动画，最多 100–160ms 淡入。强度通过 Motion Token 调整，减少动态效果取消空间运动。

## 中断和恢复
重复重试受保护，错误不清空可用旧数据；恢复焦点合理。

## 无障碍
说明原因与下一步，明确按钮，不把插图当唯一提示。

## 性能约束
不加载无意义大型插图；错误日志不含敏感信息。

## 平台适配
各平台语义文本与操作；离线状态用现有能力。核对项目实际依赖版本，不假定跨框架 API 相同。

## 验收
零数据、无匹配、权限/网络错误、重试成功和失败分别测试。记录运行环境、命令、结果和未验证项。
