# Floating Timer Pill

## 适用与禁用
活动计时需要跨页面轻量可见；不用于没有计时任务的装饰。

## 触发与状态
收起 ↔ 展开；运行 ↔ 暂停 → 完成；持久化截止时间而非递减计数。通用 focus/pressed/disabled 由原生控件承担；不适用的业务状态不伪造。

## 动画参数
展开 180–240ms；时间不逐秒缩放，时钟用截止时间计算。强度通过 Motion Token 调整，减少动态效果取消空间运动。

## 中断和恢复
关闭展开不停止任务，后台恢复重算时间；销毁清理 UI 定时器。

## 无障碍
触摸目标足够；读屏不每秒播报，操作有明确名字。

## 性能约束
更新数字局部区域；前后台切换停止不必要渲染。

## 平台适配
Web visibilitychange；Compose 生命周期；Flutter AppLifecycleState；RN AppState。核对项目实际依赖版本，不假定跨框架 API 相同。

## 验收
锁屏/后台后剩余时间正确；小屏与键盘不遮挡关键操作。记录运行环境、命令、结果和未验证项。
