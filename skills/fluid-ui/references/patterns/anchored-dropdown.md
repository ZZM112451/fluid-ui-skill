# Anchored Dropdown

## 适用与禁用
少量单选且需关联当前值；选项多时使用搜索。

## 触发与状态
关闭 ↔ 打开 → 选择/取消；disabled 不可打开。通用 focus/pressed/disabled 由原生控件承担；不适用的业务状态不伪造。

## 动画参数
100–180ms 小位移；菜单锚点边缘，遇空间不足翻转。强度通过 Motion Token 调整，减少动态效果取消空间运动。

## 中断和恢复
窗口变化重新定位；外部点击/返回关闭且不丢当前值。

## 无障碍
优先 native select；自定义时实现键盘箭头、Escape、焦点与完整 combobox 语义。

## 性能约束
不每帧测量；滚动容器定位更新受节流。

## 平台适配
原生 select/菜单优先；手机用平台选择器。核对项目实际依赖版本，不假定跨框架 API 相同。

## 验收
键盘选取/取消、滚动边界、RTL 与长选项测试。记录运行环境、命令、结果和未验证项。
