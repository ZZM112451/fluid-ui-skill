# Theme Reveal

## 适用与禁用
用户从主题控件切换明暗；不用于首次加载或每次导航。

## 触发与状态
当前主题 → 切换中 → 新主题；按钮维持焦点，加载与业务成功失败不适用。通用 focus/pressed/disabled 由原生控件承担；不适用的业务状态不伪造。

## 动画参数
180–300ms，从触发坐标裁切扩散；不支持 View Transition 时即刻切换。强度通过 Motion Token 调整，减少动态效果取消空间运动。

## 中断和恢复
后一次切换取消旧动画，主题状态先提交，旧完成回调不得回写。

## 无障碍
按钮说明当前/目标主题；forced-colors 与 reduced-motion 无扩散。

## 性能约束
禁止逐帧重绘全页或大模糊；只截一次视图，监听设备尺寸变化。

## 平台适配
Web View Transition 可选；移动端以主题状态与平台动画实现，系统主题事件同样处理。核对项目实际依赖版本，不假定跨框架 API 相同。

## 验收
连续切换 10 次最终状态正确，无白闪；两主题对比与减少动态效果通过。记录运行环境、命令、结果和未验证项。
