# Shared Element Transition

## 适用与禁用
同一对象从列表到详情；不用于无实体对应的全页缩放。

## 触发与状态
列表对象 → 转换中 → 详情；返回逆向且身份稳定。通用 focus/pressed/disabled 由原生控件承担；不适用的业务状态不伪造。

## 动画参数
220–320ms，以同一稳定 ID 协调位置与大小。强度通过 Motion Token 调整，减少动态效果取消空间运动。

## 中断和恢复
新导航中断并以路由为真；对象缺失退淡入；图片晚到不跳。

## 无障碍
减少动态效果不位移；焦点转详情标题，返回恢复源。

## 性能约束
限少量共享元素，避全屏多层纹理；性能不足直接切换。

## 平台适配
平台原生 shared element / Web View Transition 可选，不能假设 RN 跨导航库通用。核对项目实际依赖版本，不假定跨框架 API 相同。

## 验收
对象身份、返回、滚动后源位置、资源未加载均可用。记录运行环境、命令、结果和未验证项。
