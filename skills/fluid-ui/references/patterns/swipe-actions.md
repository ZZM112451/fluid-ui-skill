# Swipe Actions

## 适用与禁用
列表中少量快捷动作；破坏性操作有确认或撤销。

## 触发与状态
关闭 → 拖动 → 展开 → 操作/撤销 → 关闭。通用 focus/pressed/disabled 由原生控件承担；不适用的业务状态不伪造。

## 动画参数
位移随手指，释放 160–220ms；距离/速度双判据。强度通过 Motion Token 调整，减少动态效果取消空间运动。

## 中断和恢复
纵向滚动优先，切路由复位；同一列表只展开一个。

## 无障碍
按钮菜单等效入口；读屏可直接访问，不要求滑动。

## 性能约束
transform 跟手，限制活动行；虚拟列表用稳定 ID。

## 平台适配
原生滑动动作优先，RTL 自动反转；保留边缘返回手势。核对项目实际依赖版本，不假定跨框架 API 相同。

## 验收
纵滑、边缘返回、快速滑动、撤销、错误回滚均测试。记录运行环境、命令、结果和未验证项。
