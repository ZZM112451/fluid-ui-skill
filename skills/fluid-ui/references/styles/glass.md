# Glass

适用媒体背景、导航浮层和低密度辅助面板；不适用长篇阅读、密集表格、复杂背景上无实色衬底的正文。

以可读性选择半透明 surface，边框用有对比的中性线，圆角遵循项目 Token。模糊只作用于局部表面，不嵌套多层；滚动区域若掉帧改不透明面。不以透明度值代替最终合成后的对比检测。

浅色可从 background #eef3f0、text #172d25、accent #166447、surface rgba(255,255,255,.94) 开始；暗色 background #14231e、text #edf5f0、accent #a6e9c8。装饰渐变可关闭，不用于状态编码。border 与焦点必须有独立可见边界。

反馈采用短淡入与小位移，强度独立选择。减少动态效果禁用扩散，低性能与 forced-colors 取消 backdrop-filter，改实色。Web 使用 @supports 回退；Compose/Flutter/RN 优先平台支持的容器和模糊能力，不为效果截图整页。

验收：最复杂背景上正文可读；低性能模式功能相同；主题切换不暴露白色闪帧；不透明回退下信息层级仍完整。
