# Tech

适合监控、工程控制台和精确参数界面。深色或高对比表面、冷色强调和规则化间距支撑信息；不使用持续闪烁、扫描噪点或无因果呼吸。

浅色可用 background #eef2f5、surface #ffffff、text #152a38、accent #165b7a；暗色 background #101c25、surface #182b38、text #edf6fc、accent #8bd5fa。状态成功/错误用图标文字和颜色共同表达；精确读数采用 tabular-nums，正文保持可读系统字体。

圆角偏小但服从统一层级。最多一个操作强调，装饰发光可完全取消。高密度来自布局与可扫描性，不以小字压缩。背景网格仅在确实表达空间坐标时使用。

反馈短而确定，表达数据到达或状态变化，不让每个数字弹跳。减少动态效果和高对比模式去掉光效与位移。

验收：密集页仍有清晰焦点与标签；错误不会只靠红色；连续使用不受闪烁干扰；暗色对比度实测而非主观判断。
