# Minimal

适合任务工具、数据表、编辑与长时间使用。重点是信息优先级、对齐、文字和留白，不是隐藏功能。

基线可选 background #f5f6f3、surface #ffffff、text #192d25、muted #53665c、accent #166447、border #ccd6ce。暗色保留层级而不依赖阴影。空间以 8px 为主，表格数值右对齐并使用 tabular-nums。

边框只区分实际分组。每种强调色有语义，错误除颜色外必须有文字；主操作与次操作通过文字、边界和位置区分。可展开内容保留标题和概要，不能要求悬停才发现操作。

默认 Balanced 或 Subtle，反馈可只用 focus/pressed/加载文案。高频列表不做逐项入场；动效无价值时零动画符合此风格。

验收：键盘能发现所有操作；长文本、零条数据、错误与加载状态不破坏层级；缩小到 320px 无横向页面溢出；字体放大可回流。
