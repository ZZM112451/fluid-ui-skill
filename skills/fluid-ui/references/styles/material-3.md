# Material 3

适合 Android 和已采用 Material 体系的产品。优先 Compose Material3、Flutter Material 组件；Web/RN 在现有组件库支持时复用，不冒充未实现的原生动态配色。

使用 colorScheme 的 primary/onPrimary、surface/onSurface、error/onError，不把按钮色直接当正文色。字阶、形状与海拔通过主题统一。动态配色读取系统可用能力，并提供固定品牌配色回退。Compose 的触控与语义采用官方默认，避免自绘替代基础控件。

布局使用可用窗口宽度而非设备名称判断。底部导航在较宽窗口转 rail，弹窗宽度有上限但高度由内容和键盘约束。悬浮按钮以任务重要性决定存在，列表滚动只改变标签，不隐藏唯一操作。

动效遵循容器变化和空间关系。官方组件已有交互时不叠加第二套弹簧。减少动态效果切换不延迟业务状态。

验收：明暗及固定色回退；字体放大 200%；窗口尺寸变化与系统栏；读屏和返回不受装饰影响。
