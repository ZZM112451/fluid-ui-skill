# Crystal Motion 交付检查表

本文件用于把 Crystal Motion 从视觉参考推广到实际工程。不是发布证明。

## 每次实现必做
1. 读取项目现有设计系统、平台规范和业务状态；用户明确指定其他风格时不启用本预设。
2. 选择 Crystal Clear / Liquid Gloss / Soft Glass 的材质层级；验证背景对比度和降级。
3. 为相关交互建立稳定身份、状态机、手势与异步取消策略。
4. 同步形状、位置、宽度、内容与高光；连续输入时保留当前速度。
5. 逐项运行行为、键盘、触摸、reduce-motion、窄屏、动态字体与明暗主题检查。
6. 给出实际测试命令、结果、未验证平台；不将规范覆盖等同于组件实现。
