# 连续状态驱动形变

把界面看作同一对象的状态，不是几张独立画面。状态决定尺寸、位置、圆角、图标、标签与命中区域；动画只连接状态，不决定业务成功。

## 身份与共享进度
保留节点/组件身份与稳定 key。一个目标状态驱动所有相关属性，不分别用互不相干的 timeout 触发。连点时从当前呈现值转向最新目标；导航高亮应跟随布局中的实时边界，而不是只在 180ms/终点重新量一次。测量与写入每帧分批，限制活动对象数量，不用全页轮询。

## 不同中断策略
- 导航/FAB/胶囊：最新意图胜出，CSS/原生过渡从当前值继续。
- 主题：可以串行或明确锁定一次 720ms 过程；不丢失当前主题，副本不接收操作；窗口/偏好变化可完成到目标并清理，不留下 fill 动画。
- 复制：写入成功才 success；请求代次、反馈停留与恢复代次一致。旧 Promise 完成不得点亮另一个按钮，失败不能沿用绿色或旧成功文本。
- 分步/保存：非法输入留在原步，已确认保存只能一次；退出动画结束后关闭，关闭后的焦点回触发器；快速重开使旧关闭回调失效。
- 计时：截止时间属于业务状态；展开只改变呈现，后台恢复依据真实时间重算。

## 几何和可用性
动画不能让动态内容永久截断。弹窗将当前内容自然高度与可用安全区域取约束，字号/键盘变化重新计算；跨步移动与高度变化并发。触摸目标不能因为图标缩小而缩小到不可用。隐藏或屏幕外的操作必须从焦点顺序移除，而不是仅 opacity:0。

减少动态效果直接应用目标几何，仍给出状态文字/图标；不要仅用 .01ms 无限多个 transition 模拟禁用。高对比/低性能回退允许取消模糊和空间动画，但导航、复制、错误与取消语义必须相同。

## 证据
固定或采样动画 25%/50%/终点，检查尺寸介于两端、唯一共享指示器、主题圆心及旧/新场景关系。截图后继续或完成动画再检查终态。真实帧时间要注明环境和测量对象，不用 CSS 时长当流畅性能证据。静态文件、单张终态截图或仅检查 class 不足以证明连续形变。
