# 验证基线

## 分级证据
结构校验只能证明格式；编译只能证明目标代码可构建；运行测试证明测试路径；视觉复核证明所查看截图；真机与跨 Agent 各有独立环境。报告命令、版本、日期、成功/失败和未执行项。

## 行为
快速点击 10 次、请求失败、取消后迟到响应、旧请求晚于新请求、页面销毁、手势取消、返回恢复分别验证。成功以业务结果为准，不以动画完成为准。确保 loading 不永久阻塞，重试有意义，错误保留用户输入。

## 布局和无障碍
至少小屏与桌面、明暗、减少动态效果、长文字、200% 字体、RTL 和键盘打开。检查点击目标、标签、focus-visible、焦点顺序/恢复、Escape/系统返回、对比度和读屏。自动扫描无错误不是完整无障碍认证。

## 可测量预算
先记录目标刷新率 R，以 1000/R ms 为每帧参考预算；示例 60Hz 为约 16.7ms，不作为所有设备实测值。采集交互期间 p50/p95 帧间隔、超过参考预算的数量、>50ms 长任务、布局变化、可用时的 JS heap。注明前台/后台、无头浏览器、是否软件渲染；CI 只比较同条件样本，不承诺真机流畅。

一次只优化最明显成本。优先 transform/opacity；减少模糊面积、阴影层、解码资源和长列表 DOM。低性能开关使用实色、静态骨架和无位移动画，功能必须相同。无法获得 heap 或系统指标时记录“不支持”，不填零。

## 视觉与对照
截图固定视口、主题、字体、数据、动画稳定点。第一次截图是候选基准，必须人工查看后才能批准；与自身截图重复比较不能证明设计提升。对照实验固定任务和条件，报告模型/Agent 差异、主观评分与客观自动化指标；如无明显差异也应保留结果。
